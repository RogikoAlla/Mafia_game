# Mafia_game

Учебный проект: эмуляция игры «Мафия» на C++17. Сейчас в репозитории только каркас, который собирается и запускается. Игровой логики ещё нет.

## Что уже есть

- `CMakeLists.txt` — сборка одного исполняемого файла `mafia` со стандартом C++17.
- `src/main.cpp` — точка входа. Программа печатает одну строку и завершается с кодом 0.

Дальше по заданию появятся свой умный указатель и сама игра. Общие данные игры будут храниться в этом указателе, каждый игрок будет работать в отдельном потоке.

## Сборка

Нужны CMake 3.16 или новее, Ninja и MinGW-w64 g++ с поддержкой C++17. На этой машине компилятор стоит в `C:\mingw64` (GCC 16.2.0), каталог `C:\mingw64\bin` должен быть в `PATH`. Результат сборки лежит в каталоге `build/`, его не коммитят.

Без явного генератора CMake на Windows выбирает NMake и падает, если нет Visual Studio. Собирайте через Ninja.

Из корня репозитория, в новом терминале:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=C:/mingw64/bin/g++.exe
cmake --build build
.\build\mafia.exe
```

Ожидаемый вывод:

```text
mafia: проект собирается
```

Если `build/` уже настраивали другим генератором, удалите каталог и выполните команды заново.
